# GeoIP MMDB fixture provenance

These three MaxMind DB files are **synthetic test fixtures** generated by this
repository. They contain no MaxMind, GeoLite, or other third-party data.

- Generator: `crates/sdkwork-webserver-core/examples/geoip_fixture.rs`
- Regenerate from the repository root:

  ```text
  cargo run -p sdkwork-webserver-core --example geoip_fixture -- tests/nginx/geoip
  ```

- Database types: `GeoIP2-Country-Test`, `GeoIP2-City-Test`,
  `GeoIP2-ASN-Test` (the `-Test` suffix deliberately makes them look like the
  public MaxMind test databases; the bytes are ours).
- Build epoch: the Unix epoch (fixed), so repeated runs are byte-identical.
- Address data: RFC 5737 documentation ranges plus the loopback peer `127.0.0.1/32` (the stream GeoIP differential connects from loopback).
