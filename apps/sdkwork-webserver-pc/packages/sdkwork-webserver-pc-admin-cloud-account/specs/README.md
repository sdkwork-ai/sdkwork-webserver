# cloud-account

This package owns the cloud account capability on the backend-admin surface. It renders the same IAM-owned provider account page the tenant console does — one resource, one route set — and adds only the admin menu entry and the `admin` surface marker that selects the admin descriptive copy. The offered ownership levels are not decided here: the shared contract helper projects them from the session, so the platform admin and the tenant console cannot drift apart in which levels they offer.
