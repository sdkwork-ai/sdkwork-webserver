# sandbox

This package owns the VM Instances capability on the app-console surface: the list of virtual machine (VM) instances the authenticated operator provisioned, plus provisioning, resizing, suspend/resume, and retirement. It is a host adapter over the sdkwork-sandbox app-api face — the page contributes the menu entry, the resource key, and the form vocabulary, while the dual-token transport is composed by `@sdkwork/webserver-pc-console-core`. Ownership is not a client-side filter: the server derives the tenant and the owner from the verified principal and answers only that slice, so the page cannot be pointed at another user's instances. The state machine is the server's as well — the page offers the transitions a state admits, and a transition the server refuses (409) is reported verbatim rather than optimistically applied.
