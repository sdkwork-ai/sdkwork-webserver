# storage

This package owns the storage capability on the backend-admin surface. It is a thin host adapter over the drive-owned admin storage plane: the Storage Providers / Provider Catalog / Bindings pages and their service, types, and i18n come from `sdkwork-drive-pc-admin-storage-providers`, the bucket list and its file manager dialog come from `sdkwork-drive-pc-admin-storage-buckets`, and the shared drive dictionary comes from `sdkwork-drive-pc-commons` — the same modules cloudrouter consumes. The adapter only composes the shared admin storage SDK client (`createDriveAdminStorageHostClient`), supplies the host API base URL, and adapts the host session into the drive session snapshot the shared pages expect.
